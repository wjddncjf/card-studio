# 한 문장 스튜디오
브라우저에서 실행되는 정적 웹 편집기. 외부 이미지·라이브러리·분석 도구·서버 업로드를 사용하지 않습니다.

## 실행
`python3 -m http.server 5173 --directory dist`

## 구현
- PNG/JPEG 시그니처, 크기, 디코딩 검증 후 캔버스 재인코딩. 잘못된 파일은 현재 작업을 바꾸지 않습니다.
- 1080px 가로 캔버스로 미리보기와 PNG 다운로드를 공유합니다.
- 한글·이모지의 자소 묶음 단위 줄바꿈. 영역 높이를 넘으면 자동 축소.
- 안정된 UUID와 localStorage를 이용한 사용자 템플릿 CRUD.
- JSON 전체 검증과 이미지 재검증이 끝난 뒤 한 번만 저장. 같은 ID는 갱신합니다.
- 템플릿은 현재 브라우저에 저장됩니다. 브라우저 데이터를 지우기 전 JSON으로 백업하세요.
- 기본 색상·원형 배경은 이 프로젝트에서 직접 제작했습니다.

## 검증 상태
자바스크립트 구문 확인 및 브라우저의 문구 편집·비율 변경·템플릿 생성 확인.
과제 제출 전 극단 입력 12건, 동일 입력 결함 전후, 실제 파일 대조, JSON 및 CRUD의 전체 검증 기록을 보완해야 합니다.

## 추가 기능
위치·글자 크기·문구 너비·이미지 확대 수치 입력과 슬라이더 동기화. 이모지 스티커 최대 12개 추가, 선택, 위치·크기 조절, 삭제. 템플릿 및 JSON과 PNG에 스티커 포함. 이전 스티커 없는 버전 1 템플릿도 호환.

브라우저 확인: 90px / 60% / 1.75배 동기화, 🌷 스티커 x=80 및 크기 180 저장·새로고침·복원, 실제 PNG 열기 및 JSON 저장값 확인 PASS.

## 스티커 마우스 편집
팔레트에서 카드로 드래그해 추가, 카드 위 스티커 드래그 이동, 선택 모서리 손잡이 드래그 크기 조절. 보조 수치 입력 유지. 편집 테두리는 DOM 오버레이로 PNG에 포함되지 않음. 실제 마우스로 추가·이동·확대 확인 PASS.

선택한 스티커 왼쪽 위 휴지통으로 즉시 삭제. 기존 별도 삭제 버튼 유지. 두 스티커 중 선택한 하나만 삭제, 기존 버튼으로 마지막 스티커 삭제 확인 PASS.

글꼴 고딕/명조 선택과 추천 글자색 8종, HEX 입력 추가. 시스템 글꼴로 기기에 따라 모양은 다를 수 있음. 명조 및 파랑 저장·새로고침·복원, 잘못된 HEX 기존색 보존 확인 PASS.
